# Sudoku using Pygame
A fully playable Sudoku game built using Python and Pygame. It includes user interaction, random puzzle generation, auto-solving, conflict detection, and a fully-commented detailed solver.
---

## 🚀 Features
- Interactive 9x9 Sudoku grid

- Random puzzle generation

- Solve button (auto-solves the puzzle)

- Clear button (resets to original puzzle)

- New button (generates a new puzzle)

- Invalid move detection

- Undo support (Z key)

- Cell selection and keyboard input

- Color-coded inputs (user vs original clues).
